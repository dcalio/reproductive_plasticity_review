# reproductive_plasticity_review
Supplementary data from the following paper: "Developmental Plasticity in Insect Reproductive Morphology"

"Supp_data1" contains our manually curated dataset used for the analyses and graphs found on the paper. "Supp_data2" contains the raw result of our literature search.

Authors: Denis C. Calandriello*, Tatiana T. Torres & Bruno C. Genevcius
